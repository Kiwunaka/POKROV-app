# POKROV 1.1.6

Единое стабильное обновление для Android и Windows.

## Что изменилось

- Windows больше не остаётся в состоянии «Проверяем…», когда соединение уже подтверждено проверками POKROV.
- POKROV отличает просто запущенное другое VPN-приложение от реально занятого системного туннеля Windows. Режим системного прокси можно использовать параллельно, а при конфликте двух TUN приложение покажет понятную причину до запуска.
- Вернули фирменную иконку POKROV в системный трей.
- Исправили нечитаемый русский текст в мастере установки Windows.
- Исправили синхронизацию выданного администратором премиума: оплаченный или подаренный срок больше не должен отображаться как пробный.
- Для поддержки добавили безопасную историю технических событий приложения по аккаунту — без истории посещённых сайтов, ключей и конфигурации VPN.

## Что скачать

- **Android ARM64** — для большинства современных телефонов.
- **Android Universal** — большой запасной APK, если архитектура устройства неизвестна.
- **Windows Setup** — обычная установка; **Portable ZIP** — запуск без установки.

Android APK подписан постоянным production-ключом POKROV. Windows-сборка пока без подписи издателя, поэтому Microsoft Defender SmartScreen может попросить дополнительное подтверждение.

Обновление обязательно для старых версий POKROV.
