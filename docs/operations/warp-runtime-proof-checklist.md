# WARP connection check

The connection panel offers WARP, WARP over HTTPS (MASQUE/HTTP/2) and Psiphon. The loaded Core must advertise the selected transport. Each mode requires manual consent. MASQUE uses a separate local registration and direct bootstrap uses HTTPS DNS on the physical network. Cold helper probes run one at a time with a longer startup allowance.

When a change affects a connection helper, use the intended client package, Core and an eligible owned account. Establish the ordinary VPN state, select the helper and wait for the current runtime to report its owned egress proof. Verify traffic through the expected route. Turn the helper off and verify recovery to ordinary VPN. If a permission, registration or provider step fails, capture the closed result for that stage. Keep registration material and raw profiles private.
