# WARP connection check

When a change affects WARP, use the intended client package, Core and an eligible owned account. Establish the ordinary VPN state, select WARP and wait for the current runtime to report its owned egress proof. Verify traffic through the expected route. Turn WARP off and verify recovery to ordinary VPN. If a permission, registration or provider step fails, capture the closed result for that stage. Keep registration material and raw profiles private.
