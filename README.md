# POKROV client

POKROV is the Android and Windows client for the managed POKROV service. The Flutter shell is shared. Each native host owns permissions and its installed VPN runtime.

- [AGENTS.md](AGENTS.md) sets working rules.
- [Repository map](docs/architecture/folder-structure.md) locates the code.
- [Document index](docs/README.md) links contracts and operating procedures.
- [Local setup](docs/architecture/bootstrap-workflow.md#local-setup) and [build scripts](scripts/README.md) explain development and packaging.
- [Release procedure](docs/operations/cutover-readiness.md) covers release checks and handoff.
